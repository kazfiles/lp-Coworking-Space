# Work Base｜コワーキングスペース LP

## 概要
架空のコワーキングスペース「Work Base」の
集客用ランディングページを想定して制作しました。

初めて訪れたユーザーが
「どんな場所か」「誰向けか」「どう行動すればいいか」
を直感的に理解できる構成を意識しています。

## 使用技術
- HTML
- SCSS（Sass）
- CSS（レスポンシブ対応）

## 制作のポイント
- **ファーストビュー**
  - 背景画像に白いオーバーレイを重ね、文字の可読性を向上
  - 画面幅に応じて自然に改行される見出し設計

- **レイアウト設計**
  - Aboutセクションはテキストと画像を横並びにし、視線の流れを意識
  - スマートフォンでは縦並びに切り替え、読みやすさを優先

- **レスポンシブ対応**
  - `clamp()` を使用したフォントサイズ調整
  - メディアクエリで改行位置やレイアウトを制御
